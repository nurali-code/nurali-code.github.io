# ТЗ: Интерактивный фон Dot Grid на GSAP

## 1. Цель

Реализовать интерактивный фоновый эффект на основе примера:

https://gsapvault.com/demos/interactive-dot-grid/index.html

Необходимо повторить основную механику интерактивной сетки из точек, но адаптировать её под тёмную минималистичную стилистику моего портфолио.

Это должен быть ненавязчивый декоративный фон, который добавляет глубину интерфейсу, создаёт ощущение технологичности и реагирует на движение курсора.

**Важно:** не копировать светлую или яркую цветовую стилистику оригинала. Сохранить только концепцию и механику взаимодействия.

## 2. Визуальный стиль

Требования:

- Сетка должна быть практически незаметной в состоянии покоя.
- Не использовать яркие неоновые цвета.
- Не создавать чрезмерно интенсивное свечение.
- Исключить белые и светлые точки.
- Эффект должен органично сочетаться с чёрным фоном и фиолетовыми акцентами сайта.

## 3. Механика взаимодействия

### Сетка

Создать равномерную сетку из небольших круглых точек.

Начальные параметры:

- Размер точки: 2–3 px.
- Расстояние между точками: 22–30 px.
- Цвет: тёмно-серый с небольшой прозрачностью.
- Сетка занимает всю доступную область фонового контейнера.

### Реакция на курсор

При перемещении мыши:

1. Точки в непосредственной близости от курсора начинают плавно реагировать на его движение.
2. Вокруг курсора появляется область мягкого фиолетового свечения.
3. Ближайшие точки постепенно увеличиваются до 1.5–2 раз.
4. Их цвет плавно меняется с тёмно-серого на приглушённый фиолетовый.
5. По мере удаления курсора точки плавно возвращаются в исходное состояние.

Реакция должна распространяться радиально, с плавным затуханием интенсивности по мере удаления от курсора.

Не должно быть резких скачков размера, цвета или положения точек.

### Дополнительная динамика

Предусмотреть лёгкую инерцию:

- Реакция точек немного запаздывает относительно движения курсора.
- При быстром перемещении мыши область воздействия плавно следует за ней.
- После остановки курсора анимация постепенно затухает.
- При выходе курсора за пределы контейнера сетка возвращается в исходное состояние.

Не добавлять постоянное хаотичное движение всех точек.

## 4. Анимация и производительность

Использовать GSAP для управления анимацией.

Требования:

- Плавность движения — ориентир 60 FPS.
- Не создавать отдельный GSAP Tween для каждой точки на каждом событии mousemove.
- Использовать оптимизированный цикл обновления или пакетную обработку значений.
- Использовать requestAnimationFrame или GSAP ticker.
- Не допускать постоянных перерасчётов layout.
- Не использовать тяжёлые CSS-фильтры с blur для каждой точки.
- Не создавать лишние DOM-элементы.

Предпочтительная реализация — Canvas 2D, если это обеспечивает более высокую производительность при большом количестве точек. Альтернатива — DOM-элементы или SVG, если они позволяют точно воспроизвести механику оригинала без проблем с производительностью.

Не использовать WebGL.

## 5. Технические ограничения

Использовать:

- JavaScript (Vanilla JS).
- GSAP — уже подключённая библиотека.
- CSS.
- HTML Canvas 2D или SVG/DOM по результатам анализа производительности.

Запрещено подключать:

- Three.js.
- Particles.js.
- Vanta.js.
- PixiJS.
- Другие сторонние библиотеки и дополнительные зависимости.

Не подключать GSAP повторно, если он уже присутствует в проекте.

## 6. Адаптивность

Desktop:
- Полноценная интерактивность.
- Реакция на движение мыши.
- Оптимальное количество точек с учётом размеров экрана.

Tablet:
- Уменьшить количество точек.
- Сохранить плавную реакцию на курсор, если устройство поддерживает указатель мыши.

Mobile:
- Отключить отслеживание курсора.
- Сохранить статичную сетку с очень слабым фиолетовым оттенком.
- Не использовать постоянную анимацию без необходимости.

## 7. Интеграция в существующий сайт

Фон должен быть отдельным независимым компонентом.

Требования:

- Разместить его позади основного содержимого сайта.
- Использовать position: fixed или absolute в зависимости от существующей структуры проекта.
- Не блокировать клики и взаимодействие с интерфейсом (pointer-events: none).
- Не влиять на размеры и позиционирование других элементов.
- Не перекрывать текст, изображения и карточки проектов.
- Корректно работать при прокрутке страницы.
- Поддерживать изменение размеров окна браузера.
- Предусмотреть корректную очистку обработчиков событий и GSAP-анимаций при уничтожении компонента.

## 8. Доступность

- Учитывать prefers-reduced-motion.
- При включённом ограничении движения показывать только статичную сетку.
- Не создавать мерцаний и резких вспышек.
- Не использовать эффект, который отвлекает от основного содержимого сайта.

## 9. Критерии готовности

Результат должен соответствовать следующим условиям:

1. Механика интерактивной сетки визуально соответствует референсу.
2. Цветовая гамма полностью адаптирована под тёмный интерфейс.
3. В состоянии покоя фон практически незаметен.
4. При движении мыши появляется мягкая фиолетовая реакция.
5. После ухода курсора эффект плавно исчезает.
6. Нет заметных просадок FPS.
7. На мобильных устройствах фон не создаёт лишней нагрузки.
8. Нет новых сторонних библиотек.
9. Реализация не нарушает существующую вёрстку и функциональность сайта.

## 10. Порядок выполнения

Перед началом:

1. Изучи структуру существующего проекта.
2. Проверь, как подключён GSAP.
3. Проанализируй оригинальный референс и его механику.
4. Определи наиболее производительный способ реализации.
5. Реализуй эффект отдельным компонентом.
6. Проверь работу на desktop, tablet и mobile.

Не переписывай существующие секции сайта. Не изменяй дизайн портфолио. Задача касается исключительно фонового эффекта.

**Главный приоритет:** визуальная точность взаимодействия, сдержанный внешний вид и минимальная нагрузка на браузер.
